# MSDS--TDS

冠志（广州冠志/国彩）MSDS / TDS 自动化生产系统：从 MSDS 解析、标准字段库建设、
危险性推断、覆写生成到多格式输出的完整工具链，按 GB/T 16483 / GB 30000 系列等标准组织。

> 本仓库只收录**程序、技能、插件、文档、模板与结构化库表**；
> 具体产品的 MSDS / TDS 原始文档（docx/pdf）与法规原文 PDF 不收录（数据资产，体积大且含业务信息），
> 模板与结构化数据见 `03-数据库/定稿模板` 与 `03-数据库/Data Base`。

## 模块地图

- **02-检索系统** 是完整可运行包（结构读取）：`python main.py` 启动 GUI；
  `python main.py --cli <docx>` / `--extract`；`tools/build_msds_db.py` 负责 SQLite 建库与数据库检索（见 03-数据库）。
- **03-数据库** 中的 `core/`、`tools/`、`docs/` 为 02-检索系统 同源文件（运行以 02 为准），此处按「数据库」职能归类展示。
- **01-表单系统** 的 `gui/form_window.py`、`core/form_schema.py` 亦为 02-检索系统 同源组件。
- 各模块间的数据流：**表单系统采集 S1/S3/S9 → 推断引擎补齐 S2/S4~16 → 覆写引擎套模板格式 → 多格式输出**；
  检索系统与数据库贯穿全程（解析/入库/检索）。

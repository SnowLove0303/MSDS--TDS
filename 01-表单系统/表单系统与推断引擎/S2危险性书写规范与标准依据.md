# MSDS 危险性概述（S2）书写规范与标准依据

> 用途：推断引擎设计 S2 危险性规则库的权威依据。
> 事实基础：扫描全库 429 个去重 MSDS 的真实 S2 分类，证明危险性必须按
> GHS 分类体系组合式生成，不能用「危险 vs 非危险」二分法。

## 一、必须参照的法规与标准（按效力层级）

### 1. 法规（强制性）

| 依据 | 要求 |
|---|---|
| 《危险化学品安全管理条例》（国务院令第591号，2011） | 第15条：危险化学品生产企业必须提供与其产品相符的化学品安全技术说明书（SDS），并在包装粘贴/拴挂安全标签 |
| 《危险化学品登记管理办法》 | 危化品登记须提交 SDS |
| 《危险化学品目录（2015版）》（十部门公告） | 判定产品是否属于危险化学品的官方清单（2828条目）；目录内物质/混合物需按危化品强制管理 |
| 《新化学物质环境管理登记办法》 | 新化学物质登记需提交 SDS/环境风险评估资料 |

### 2. 标准（技术依据）

| 标准号 | 名称 | 作用 |
|---|---|---|
| GB/T 16483-2008 | 化学品安全技术说明书 内容和项目顺序 | 规定 SDS 的 16 部分框架与各部分内容要求（S2 结构依据） |
| GB/T 17519-2013 | 化学品安全技术说明书 编写指南 | 各部分的详细编写方法、数据来源、格式要求 |
| GB 13690-2009 | 化学品分类和危险性公示 通则 | 危险性分类体系总则 + 公示要求（SDS/标签） |
| GB 30000.2~29-2013 | 化学品分类和标签规范（28部分） | 逐类定义 GHS 危险性类别的分类标准、象形图、信号词、H/P 码 |
| GB 15258-2009 | 化学品安全标签编写规定 | 安全标签要素（与 SDS 的 S2 标签要素对应） |
| UN GHS 紫皮书 | 全球化学品统一分类和标签制度 | 国际源头，GB 30000 系列对应 GHS 第4修订版 |

### 3. GB 30000 系列（28 部分）覆盖的全部危险性类别

物理危险 16 类：
GB 30000.2 爆炸物；.3 易燃气体；.4 气溶胶；.5 氧化性气体；.6 加压气体；
.7 易燃液体；.8 易燃固体；.9 自反应物质；.10 自燃液体；.11 自燃固体；
.12 自热物质；.13 遇水放出易燃气体；.14 氧化性液体；.15 氧化性固体；
.16 有机过氧化物；.17 金属腐蚀物。

健康危害 10 类：
GB 30000.18 急性毒性；.19 皮肤腐蚀/刺激；.20 严重眼损伤/眼刺激；
.21 呼吸道或皮肤致敏；.22 生殖细胞致突变性；.23 致癌性；.24 生殖毒性；
.25 特异性靶器官毒性（单次）；.26 特异性靶器官毒性（反复）；.27 吸入危害。

环境危害 2 类：
GB 30000.28 危害水生环境（急性1、慢性1-4）；.29 危害臭氧层。

## 二、S2 危险性概述的书写结构（GB/T 16483-2008 第2部分）

| 子项 | 内容规范 | 示例 |
|---|---|---|
| 2.1 危险性类别 | 按 GB 30000 分类结果，类别名 + 类别 + H码 | 易燃液体，类别 4（H227） |
| 2.2 象形图 | GHS 象形图（GHS01-GHS09），非危险可无 | 根据GHS不属于危险物 |
| 2.3 信号词 | 仅两个选项：危险 / 警告（非危险无） | 警告 |
| 2.4 危险性说明 | 每条以 H 码开头 + 中文说明 | H316 造成轻微皮肤刺激。 |
| 2.5 防范说明 | 每条以 P 码开头 + 中文说明 | P210 远离热源、热表面、火花、明火。 |
| 2.6 其他危险 | 环境危害/特殊危害补充 | 喷涂时可能形成气溶胶。 |

### 关键格式规则

1. 危险性类别文字 = 类别名（中文）+ 逗号 + 类别编号 + 括号 H 码。
   例：对水环境有慢性危害, 类别 3 (H412)；急性毒性，吸入性，类别 4 (H332)。
2. 信号词由分类严重度决定：Cat 1/1A/1B/2 → 危险；Cat 3/4 → 警告；多个分类取最严重。
3. 危险性说明 / 防范说明的每一条必须带 H/P 码，多类别时分行列出。
4. 非危险物（不属于危险/不属于危害）时：2.1~2.5 写「根据GHS不属于危险物」，2.6 可空。
5. 象形图按分类自动匹配（GHS01 爆炸、GHS02 易燃、GHS03 氧化、GHS04 加压、
   GHS05 腐蚀、GHS06 急性毒、GHS07 感叹号、GHS08 健康危害、GHS09 环境）。

## 三、真实库证据：危险性必须组合式生成

扫描 429 个去重 MSDS 的 S2 分类统计：

- 非危险（不属于危险/危害）：202 个
- 单危险类别：67 个
- 多危险类别（>=2）：83 个
- 空 / 无：67 个

H 码覆盖 Top：H412 水生慢性3(90)、H332 吸入急性毒4(63)、H317 皮肤致敏(61)、
H335 呼吸道刺激3(45)、H360 生殖毒(43)、H373 STOT-RE(32)、H320 眼刺激2A(20)、
H226 易燃液体3(16)、H316 皮肤刺激3(16)、H370 STOT-SE(16) ...
共 20+ 种 H 码，83 个文件含多个危险类别。

结论：**危险性 = 若干 GHS 类别按规则组合**，每个类别贡献「类别行 + 象形图 +
信号词贡献 + H码 + 对应P码」，最后合并成 S2 文本。这正是推断引擎规则库的形态。

## 四、推断引擎 S2 规则库设计

### 数据源分层
1. 分类数据库：CAS 号 → GHS 分类（首选《危险化学品目录》分类信息或供应商提供的
   SDS 分类；建立成分-分类索引表，外部 JSON 配置）。
2. 物性判定：CAS 未命中时，用 S9 物理性质按 GB 30000 分类标准判定物理危险
   （闪点 → 易燃液体类别；自燃温度 → 自热；氧化性；爆炸特性 → 爆炸物）。
3. 健康/环境危害：需数据库或专家输入，推断器标注「需人工确认」。

### 规则库 JSON 形态（建议）

```json
{
  "categories": {
    "易燃液体-2": {
      "category": "易燃液体，类别 2（H225）",
      "pictogram": "GHS02",
      "signal": "危险",
      "h_codes": ["H225"],
      "p_codes": ["P210", "P233", "P240", "..."]
    },
    "急性毒性-4": {
      "category": "急性毒性，吸入性，类别 4（H332）",
      "pictogram": "GHS07",
      "signal": "警告",
      "h_codes": ["H332"],
      "p_codes": ["P261", "P271", "P304+P340", "..."]
    }
  },
  "non_hazard_text": "根据GHS不属于危险物",
  "merger": "信号词取最严重、H/P码合并去重、象形图去重、分行输出"
}
```

### 生成流程
1. 输入 S3 成分(CAS) + S9 物性。
2. 查成分-分类索引 → 得到危险类别集合。
3. 未命中 → 物性判定 + 标记低置信度。
4. 按 merger 规则合并：象形图去重、信号词取最严重、H码/P码按 GHS 附录取对应
   中文说明，分行组装成 S2 六子项。
5. 输出带 confidence（database > physical > needs_review）。

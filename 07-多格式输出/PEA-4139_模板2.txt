[2] 2.危险性概述
    ├─ 2.1 GHS危险性类别: 易燃液体，类别4（H227）
    ├─ 2.2 GHS标签要素
    │   └─ GHS象形图: 无
    ├─ 2.3 信号词: 警告
    ├─ 2.4 危险性说明: H316造成轻微皮肤刺激。
H320造成眼睛刺激。
H332吸入有害。
H360可能对生育能力或胎儿造成伤害。
H370可能对器官的伤害。
H373长期或重复暴露可能会对器官造成伤害（肝）。
    ├─ 2.5 防范说明: 预防措施：
P210 远离热源、热表面、火花、明火和其他点火源。禁止吸烟。
P280 戴防护手套/戴防护眼罩/戴防护面具。
P370+P378 火灾时：使用雾状水、抗溶性泡沫、干粉或二氧化碳灭火。
P403+P235 存放在通风良好的地方。保持低温。
P501 按照当地法规处置内装物和容器。
    ├─ 2.6 其他危险: 喷涂使用时可能形成雾滴或气溶胶，应避免吸入。
产品进入眼睛可能造成短暂刺激或不适。

[4] 4.急救措施
    ├─ 4.1 一般措施: 立即脱掉所有被污染的衣物。
    ├─ 4.2 误服: 若意外吞食，不要催吐，立即就医。无意识时，不要经口喂食任何食物。
    ├─ 4.3 接触眼睛: 立即翻起上下眼睑用大量缓和流动的水清洗眼睛至少20 分钟。且将头倾斜，避免化学品流入另一只未受污染的眼睛，并立即就医。
    ├─ 4.4 接触皮肤: 立即用肥皂和大量的水冲洗。若发生皮肤反应，就医。
    ├─ 4.5 吸入: 一旦吸入，如有不适，就医。
[5] 5.消防措施
    ├─ 5.1 合适的灭火剂: 二氧化碳（CO2），耐醇泡沫，化学干粉。大火时应用水喷洒。
    ├─ 5.2 不合适的灭火剂: 高流量的水喷射。
    ├─ 5.3 物质或混合物的特殊危害: 燃烧时释放一氧化碳、二氧化碳、氮氧化物等。
在着火或爆炸情况下，不要吸进烟尘。
    ├─ 5.4 消防预防措施和保护设备: 消防人员必须佩戴自供气式呼吸器。
禁止污染的灭火用水流入土壤，地下水或地表水中。
[6] 6.意外泄漏措施
    ├─ 6.1 个人预防措施、应急程序: 戴防护设备。确保充分的通风/排气。
令未授权人员离开。
    ├─ 6.2 环境保护措施: 禁止排入下水道，废水或土壤中。
    ├─ 6.3 污染物收集和清除的方法: 用化学品吸收材料或必要时用干沙收集，并储存于密闭容器中。
[7] 7.操作和储存
    ├─ 7.1 安全操作防范: 在具有适当排气通风的场所使用。避免与皮肤和眼睛接触。不要呼吸蒸气或喷雾。远离食物，饮料和烟草，休息前及工作结束及时洗手。更换被污染或浸湿的衣物。
    ├─ 7.2 安全储存条件: 容器保持紧闭，存储在凉爽通风处。为保证产品质量，必须遵守我们产品信息表的储存条件。

[11] 11.毒性资料
    ├─ 11.1 急性毒性: 经口： 半数致死剂量（LD50）/大鼠：约3,306 mg/kg。
吸入： 半数致死浓度（LC50）/4 h/大鼠： ＞1.5 mg/L（气溶胶）。
经皮： 半数致死剂量（LD50）/兔：2,764 mg/kg。
根据现有数据，二乙二醇单丁醚未达到急性经口、 经皮或气溶胶吸入毒性的分类标准。
    ├─ 11.2 主要皮肤刺激性: 物种：兔子
分类：根据现有数据，不属于皮肤腐蚀或皮肤刺激类
结果：长时间或反复接触可能造成皮肤干燥
    ├─ 11.3 主要眼睛刺激性: 物种：兔子
分类：刺激眼睛
结果：未稀释的二乙二醇单丁醚可造成明显眼睛刺激，
    ├─ 11.4 致敏性: 物种：豚鼠
分类：根据现有资料，不属于皮肤致敏物质
结果：动物试验中未观察到皮肤过敏反应。
    ├─ 11.5 致突变性: 多数细菌回复突变试验及染色体畸变试验结果为阴性。 部分体外基因突变试验结果存在差异。
    ├─ 11.6 致癌性: 在动物试验中未见致癌影响。
    ├─ 11.7 生殖毒性: 根据现有动物试验，二乙二醇单丁醚未表现出明显的 生育能力损害、致畸作用或发育毒性。
    ├─ 11.8 特异性靶器官系统毒性: 根据现有资料，未达到特异性靶器官毒性 一次接触的分类标准。
    ├─ 11.9 吸入危险: 无数据资料。
    ├─ 11.10 附加信息: 眼睛接触可能造成明显刺激、发红及疼痛。
长时间或反复皮肤接触可能造成轻微刺激、 皮肤发红或皮肤干燥。
正常温度下蒸气压较低，单次蒸气暴露通常不预期造成明显不良影响；
喷涂、加热或形成气溶胶时， 应保持良好通风并避免吸入。 误食较大剂量可能造成不适。
